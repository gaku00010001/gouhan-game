# 合板ファクトリー

丸太から合板ができるまでの8つの工程を、ミニゲームで体験できるブラウザゲームです。

## 遊び方
`合板ファクトリー.html` をブラウザで開くだけで遊べます（インストール不要・スマホ対応）。

## 工程
1. 🪚 玉切り — ノコギリを印に合わせて切る
2. 🌲 剥皮 — なぞって樹皮をはがす
3. 🌀 ロータリーレース — 長押しで単板の厚みをキープ
4. ♨️ 乾燥 — 温度を調整して含水率8〜12%で取り出す
5. 🔍 選別 — 単板を表板・心板・補修行きに仕分け
6. 🧩 組み立て — 木目を直交させて積層、心板に接着剤
7. 🔥 熱圧 — 連打でプレス圧を適正に保つ
8. ✨ 仕上げ — なぞって表面を研磨

各工程100点満点・合計800点で職人ランク（S〜D）が決まります。
