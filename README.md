## 学べること
- **注文を選んでスタート**：構造用合板・コンクリート型枠用合板（コンパネ）・普通合板から選び、使い道に合った合板づくりに挑戦
- **各工程の解説**：「実際の工場では」「ここがポイント」で工程の目的と理由を説明
- **確認クイズ**：工程ごとに問題バンクからランダム出題、解説つき（全20問）
- **工程どうしのつながり**：乾燥での含水率が熱圧の「パンク」に影響するなど、因果関係を体験
- **接着性能の選択**：使い道に合わせて特類・1類・2類を選ぶ
- **製品検査レポート**：寸法・厚さ・含水率・構成・接着性能などを判定し、不合格の理由も表示
- **復習**：まちがえたクイズを最後にまとめて表示
- **用語集**：合板の専門用語33語をいつでも確認・検索

## 工程
1. 🪚 玉切り — ノコギリを印に合わせて切る
2. 🌲 剥皮 — なぞって樹皮をはがす
3. 🌀 ロータリーレース — 長押しで注文に合った単板の厚さをキープ
4. ♨️ 乾燥 — 温度を調整して含水率8〜12%で取り出す
5. 🔍 選別・補修 — 単板を表板・心板・補修行きに仕分け
6. 🧩 組み立て — 木目を直交させて積層、のり付け、接着剤の性能を選択
7. 🔥 熱圧 — 連打でプレス圧を適正に保つ（含水率が高いとパンク）
8. ✨ 仕上げ・検査 — 出荷前の合板から不良（膨れ・はく離・割れなど）を見つけてタップ

各工程の技能点（100点満点）とクイズの知識点の合計で、職人ランク（S〜D）が決まります。
